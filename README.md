### 1. 原始产品愿景（尚未全部达成，不作为已完成功能清单）
本项目是一个专门用于实时抓取并聚合国内外各大主流平台（包括哔哩哔哩/B站、抖音、YouTube、TikTok、Twitter等）最新最热榜单视频的监测与学习分析平台。用户可以通过清爽、细腻的 Obsidian 风格暗黑界面，第一时间获取各类爆款热点（如鬼畜、搞笑、科技、穿搭、商业营销等）。任何视频都可以点击中间的播放按钮，直接以优雅的**放大弹窗**形式在网页中无缝播放；针对短视频，平台还集成了**无水印/MP4直链极速嗅探提取工具**，并配合**AI智能拆条**，自动提取视频的黄金脚本看点与二创/模仿学习建议，帮助视频创作者轻松学习爆款流量密码。

### 2. 如何启动项目

按照以下步骤即可在本地快速运行项目：

1. **准备网络环境**：
   如果要抓取 YouTube、TikTok 或 Twitter 的内容，请确保您的电脑开启了代理软件（如 Clash Verge 等），系统在启动时会自动测试并连接您的本地代理端口（默认自动尝试 `http://127.0.0.1:7897` 和 `7890`）。

2. **安装依赖**：
   在项目根目录下（`d:\Extends\antigravityProj\HotPot`）打开命令行终端，运行以下命令安装项目所需组件：
   ```bash
   npm install
   ```

3. **启动服务器**：
   运行以下命令开启后端服务：
   ```bash
   npm start
   ```
   服务会先检测代理，再监听4000端口。出现 `Server is running at http://localhost:4000` 后即可访问；访问受限的平台会单独报错，不影响本地账号与已接通的数据源。

4. **访问系统**：
   在浏览器（推荐使用 Chrome 或 Edge 浏览器）中输入并访问：
   **[http://localhost:4000](http://localhost:4000)**

### 3. 技术栈介绍（大白话科普）

为了让不懂编程的小白也能轻松理解，下面用大白话来解释这个系统背后的“黑科技”：

* **Node.js (运行环境)**
  * **大白话**：它就像是电脑上的一个**“翻译官兼发动机”**。原本 JavaScript 这种编程语言只能在网页浏览器里运行，Node.js 把它释放了出来，让它能在你的电脑系统里运行，这样我们才能写出各种能够抓取数据、管理文件的后台程序。
* **Express (Web 服务框架)**
  * **大白话**：它是一个**“毛坯房框架”**或网页的**“前台接待员”**。当你在浏览器里输入网址或点击刷新时，就是向后台发送了一个请求。Express 负责把守门口，收到请求后，大叫一声“来客了”，然后把对应的数据或网页端端正正地打包送回给你的浏览器。
* **Axios (HTTP 请求库)**
  * **大白话**：专门在网络上跑腿的**“快递员”**或**“自动送信件的机器”**。后端程序不能像我们人类一样用鼠标在浏览器上点开B站或抖音，所以我们用 Axios 自动往各大网站的服务器发送信件，把最新的热门数据“打包”拿回咱们自己家里。
* **Puppeteer (无头浏览器)**
  * **大白话**：一个**“没有屏幕、完全由代码自动操控的隐形浏览器”**。很多海外网站（比如 TikTok 的镜像网站）为了防爬虫，或者需要网页里的 JavaScript 复杂运行完才能展示视频，一般的“快递员”Axios 拿不到。我们就派这个隐形的浏览器模拟真人进去访问，默默等到视频播放流出现，再把它的 MP4 地址复制出来。
* **API (应用程序接口)**
  * **大白话**：餐馆里的**“传菜员”**。前台（浏览器）点了一盘“B站热门视频”，传菜员（API）把单子送到厨房（服务器后台），大厨（爬虫程序）把菜做好之后，传菜员再把这盘菜稳稳地端到你桌上。
* **Proxy (网络代理)**
  * **大白话**：网络世界的**“海外代购”**。因为国内网络直接去 YouTube 或 TikTok 会“迷路”被墙，我们只要给国内的“代购小哥”（代理软件，如 Clash）打个招呼，小哥就会在海外把 YouTube 视频买（抓取）回来递给我们，这样我们就也能在本地看到了。
* **CORS & Referer (跨域与来源保护防盗链)**
  * **大白话**：网络世界里的**“小区保安和盖章证明”**。B站封面的图片带有“防盗链”功能——它会检查你是在哪里看这张图的，如果发现是在我们自己的本地小网站（localhost）看，保安就不允许通过，导致图片显示裂开。我们在后台做了一个**“图片代购代理”**，假装我们是B站自己人在请求图片，保安盖章放行，封面就顺利加载出来了。
* **DOM (文档对象模型)**
  * **大白话**：网页的**“骨架图”**。网页里的标题、图片、按钮都是一个个拼图块，DOM 就是这张拼图的位置表。我们的 `app.js` 脚本就是通过 DOM 找到这些拼图的位置，把我们刚拿回来的热门视频标题、封面和链接准确无误地填进去，呈现在你的面前。
