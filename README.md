# HotPot · 万热观象

多平台公开视频发现、指标对比与字幕/原声学习工作台，配有暗色榜单界面和城市关联地球。

**当前定位：可继续开发的单进程应用，不是已验收的“全平台、全历史、实时总榜”。** 视频信息可见、播放量可核验、可下载、可转写是四种不同能力；不会因为有封面或点赞就视为全部成功。默认使用流程不要求用户扫码或手机登录。

更新：2026-10-25。当前基线`917d476`/`hotpot-wip`已保全前轮代码，新增[原作者GitHub/官方来源调研及接手方案](docs/HANDOFF_2026-10-25_SOURCES.md)。TikTok缓存响应补指标、更新null保护与YouTube独立JS运行时已起步；抖音/小红书匿名播放仍未解决，不将候选服务视为接通。10月23日首批修复另见[历史实现记录](docs/IMPLEMENTATION_2026-10-23.md)。

## 当前可做什么

- 浏览 B站、抖音、YouTube、TikTok、X、小红书和快手的已发现作品；按发布时效、分类和关键词筛选，前端每批展示30条。
- 默认按已取得的播放量排序，可显式切换公开点赞；未知指标不排名。新增适配器的精度/筛选回归已做首批修复；没有可靠上游续页的路径明确只提供本批样本，不假称无限分页。
- 独立查看已接入的平台话题榜；当前主话题接口仅支持B站、抖音，不是七平台全部接通。
- 查询本机可恢复的已采集记录；数据是最后一次实际观测，不是全站历史库或播放增长时序库。
- 查看视频内容地名关联的3D地球：本地概览、国家分色/名称、城市点位和可选网络瓦片。不是作者IP、拍摄位置或城市人口热度。
- 解析可访问的公开链接；提取平台字幕或以原声ASR转写，再进行文本总结与时间戳引用；准备MP4/MP3。不是画面、镜头或OCR分析，也不保证任意平台任意作品成功。
- 免登录访客任务按浏览器临时会话隔离；可选真实账号提供账号历史和资料管理。

## 先知道的缺口

1. **抖音、小红书仍未取得稳定、可核验的匿名作品播放量。** 话题热度、点赞、收藏/评论合计与零占位均不能替代播放。
2. TikTok/抖音详情补全接线、匿名同源与有界队列，以及YouTube分类/时效/精度已有代码修复；仍未做真实原站验收，后台指标应用反馈和真实续页还要继续。
3. 长任务预占、索引内过期目录、空会话容量与跨日额度已做最小修复；历史无索引orphan、会话创建速率、整任务磁盘/流量预算仍待完成。
4. 安装器目前针对 Windows x64；Linux媒体环境、生产反向代理和多实例运行没有完成验收。

详情与下一步顺序见 [接手入口](HANDOFF.md) 和 [本次问题清单](docs/REVIEW_2026-10-21.md)。

## 本地开发启动

仓库有 `pnpm-lock.yaml`，但包管理器尚未统一，`pnpm-workspace.yaml` 的 Puppeteer 构建许可仍是占位值；下面的 `npm install` 是现有开发安装路径，**不是冻结锁、冷机可复现部署方案**。

```powershell
npm install
npm start
```

默认只监听 `127.0.0.1:4000`，访问 [本地页面](http://localhost:4000)。模型缺失不妨碍只看榜单；完整本地媒体处理在 Windows x64 上另执行：

```powershell
npm run setup:media
```

这会安装私有Python/媒体/本地LLM运行环境并下载约4GB模型，需要额外磁盘、安装网络和执行时间。不要在已具备环境时反复安装；不要把“模型文件存在”当成真实任务验证通过。

现有本机基线为 Node 20.20.0，但20系列已EOL。服务器应先在受支持LTS（例如24）验证全部依赖和媒体模型，再固定运行版本；不要直接升级生产运行时。[Node官方发布状态](https://nodejs.org/en/about/previous-releases)

## 网络与使用边界

服务端海外采集可能需要 `MEDIA_PROXY`；自动检测的是**运行服务器自己的**本机代理端口，不是开发电脑的代理。浏览器中的嵌入播放器、图标CDN和地图瓦片是另一条网络路径，服务器配置代理不一定能解决客户端不可达。

匿名访问受平台公开范围、地区、限流和页面变化影响。可选运营者API凭证不是终端用户登录要求，也不代表已经获批或实测接通。仅处理自己拥有权利或已获授权的内容；不绕过验证码、私密或付费访问。
