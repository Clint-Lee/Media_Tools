# 免登录使用、实测与数据边界（2026-10-15）

## 临时设备直接使用

运行服务后打开 [HotPot](http://localhost:4000)，直接浏览榜单，或到媒体工作台粘贴公开视频链接进行解析、字幕/语音转写、内容总结、MP4/MP3下载。无需HotPot账号、平台账号、手机、短信验证码或扫码。当前机器的模型已安装，不用重新下载。

如服务尚未启动，在项目 `D:\Extends\antigravityProj\HotPot` 中运行：

```powershell
npm start
```

“免登录”使用的是匿名访问，而不是共用他人的账号。抖音精选与TikTok发现页使用全新隔离浏览器，不注入个人登录Cookie；平台自己发的技术Cookie不代表登录。媒体任务以HttpOnly访客Cookie区分所有者，另一访客不能读取你的文件/历史，管理员配置仍需真实管理权限。

访客每浏览器会话每日20次处理、同IP每日60次，解析与新任务分别计次，失败退回；单任务2GB、后台串行处理。访客Cookie最长8小时，历史驻当前服务内存、最多100条，重启清空；完成文件保留1小时。账号仅用于可选的持久历史/资料。公共临时设备建议使用隐私窗口，使用完关闭；不要留下下载到本机的私人文件。

海外公开站点仍需运行服务器的网络可达，`MEDIA_PROXY`是网络配置、不是登录。旧`platform:login`仅保留为运营者可选高级工具，不是现行用户流程，也不会让受限指标凭空公开。不要把密码、Cookie或API Key发到聊天。

## 为什么抖音可能仍没有播放量

此前把抖音热搜话题转成视频卡片的回退已移除。话题标题、话题封面、事件热度、事件时间，不能充当某条作品的标题、封面、播放量和发布时间。

视频列表现在统一按真实 `playRaw` 降序。有真实播放计数才参与名次；缺少播放量的作品显示“播放量未公开 / 未入播放榜”，放在末尾，点赞另列且不参与排序。网页接口用0占位隐藏抖音播放量时保持未知，不把0当成已验证计数。不会用点赞乘倍数估算。

普通网页登录不意味着能读取任意作者的播放量。[抖音官方视频数据接口说明](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/search-video/video-data)列有 `play_count`，同时要求用户授权与接口权限。这不是面向游客的全网播放榜；旧文档可见也不保证你的应用当前获准调用。当前项目没有完成作者OAuth授权数据接入，不能宣称支持抖音全网真实播放总榜。

## 可选的运营者API配置（不是用户登录）

- YouTube目前可读取部分公开视频搜索。运营者若需要精确日期、官方分类、可靠翻页，可在官方Google Cloud项目启用YouTube Data API并取得API Key，在服务器.env配置 `YOUTUBE_API_KEY=...`，然后重启服务。无需最终用户登录；不要把Key写到前端或发到聊天。
- X官方搜索需要有对应搜索权限/额度的 `X_BEARER_TOKEN`，在.env配置后重启。只持有普通X账号不等于有API权限。近7天与历史搜索权限不同，历史模式还需 `X_SEARCH_ARCHIVE=1`；不能只打开该开关冒充已有权限。
- 官方API可能有额度、费用或权限限制；不自动开通、不代购权限，也不通过开关冒充获得授权。

## 首屏速度与地球如何判断是否正确

- 每次首批固定30条，不再随屏宽改成25条。懒加载只减少渲染工作，不能消除上游查询耗时。
- 首屏不加载地球库，不等待远程Google字体；账号、设置、视频请求并行。真实采集快照保留至多30分钟，过期后带“快照/后台更新”标记显示，绝不把旧采集时间改成现在。强制刷新仍会等待上游。
- 部分上游失败时，会明确标注保留30分钟内此前实际采集的候选，避免一次接口失败把真实作品全清空；不会给保留记录补新播放量或新发布时间。全部更新失败会短暂退避，避免前端轮询频繁打上游。
- 抖音/TikTok公开发现流会自然轮换，刷新时同一筛选下30分钟内的已采集作品可继续保留并标缓存，不会跨分类/时效塞入其它作品。分区切换按请求发起代次隔离，旧分区晚到的响应不会混入新分区。真实候选不足30条时不凑假数，可继续请求上游。
- 地球默认“已采集平台汇总”，可以切到“当前平台”。当前抖音视频受限时，汇总可以显示此前实际采集的B站等样本，但明确写出平台范围；不是暗中把B站数据算给抖音。
- 白色城市名称只是地理参考，彩色点/柱和数字才表示视频关联数量。默认卫星+本地中文城市名，也可选OpenStreetMap街道瓦片；瓦片不可达时明确保留原底图，不影响实际城市统计。地图有版权标注，按当前视角请求，不批量预下载。
- 只有明确城市关联的作品才计数；未匹配地名不代表视频不存在，更不能推测其作者所在地。没有GPS/可靠位置字段时，这是内容城市关联，不是真实IP来源统计。

回归：`npm test`、`npm run test:guest-media`、`npm run test:guest-ui`、`npm run test:anonymous-media`、`npm run test:experience`。媒体/浏览器报告位于私有`.cache/verification/`，不可随项目分发访客Cookie、账号、媒体原件。联网结果会变化，不能把一次通过写成永久100%可用；`test:anonymous-media`是逐项记录诊断，不是无条件全平台通过断言。
