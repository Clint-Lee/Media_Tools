# 平台接入与真实能力边界

文档定稿：2026-10-23；审查日期2026-10-21，续查基线仍为`48b6afb`。本表描述代码路径及已确认缺口，**不是本轮全平台实时连通结果**。数量、排名和计数会随平台/网络变化，不能搬用旧设备的样本数。

## 默认免登录

普通用户浏览榜单、解析可访问公开链接、提交字幕/原声分析及下载，不要求HotPot账号、手机验证码或平台扫码。匿名浏览器可能持有原站正常发放的技术Cookie，这不是个人登录。

平台不公开的数据不会因“免登录产品”自动公开；受限时必须说明范围和失败。运营者可选API/授权配置不能被表述为临时设备的前提，也不能用来共享个人私有内容权限。

话题榜的热度/作品数不能进入视频播放排序；发布时效筛选只约束关联作品，不等同过滤热搜发生时间。

## 指标读法

- 播放量、点赞、评论、分享和收藏分别保留；缺失不填0，不按点赞率推播放。
- 原站整数可作数值排名；`1.2M/1.2万`是平台缩写，应保留原文并标近似；`10万+`只有下界，不是精确100000名次。
- 播放/点赞有各自来源与观测时间；缓存筛选不能刷新采集时刻，新指标也不能被旧详情覆盖。
- 榜单名次只适用于已取得的作品。样本少/空可能是发现覆盖、严格日期或访问失败，不能解释成平台总共只有几件视频。
- 上述是统一契约；相应已知违反项已做首批代码修复，但未等于原站全面验收，详见[实现范围](IMPLEMENTATION_2026-10-23.md)及修前[R01–R08](REVIEW_2026-10-21.md)。

## 媒体与分析

可访问链接才有后续解析机会；需核对作品ID、真实媒体响应、音轨与文件格式。字幕优先，无法取得时可对真实音频ASR；再做文本总结和时间戳引用。语音/专名可能识别有误，LLM可能误解，用户应能回看原句。

原句摘录降级不等于AI语义分析；模型文件存在不等于加载和本次任务成功。当前不含画面/OCR/镜头理解。MP4为可取得流的封装/合成，不保证任意视频质量、所有编码可用或去掉内嵌水印。

## 临时设备与服务器

访客通过HttpOnly会话隔离结果，当前会话令牌约8小时有效；历史主要在服务内存，重启不保证恢复访客历史。设计额度为访客每日20次、同IP60次，解析与任务分别计次、失败退回；跨日、空会话和长任务预占已通过隔离修复；仍需创建速率/可信IP/总资源限制，不能视作完整公网限流。

媒体文件设计保留约1小时，但索引内启动过期清理已修，历史已丢索引的orphan仍待受控盘点；不要承诺到点必删，也不要把临时任务当永久存储。公共设备建议隐私窗口，使用后关闭并自行管理本机下载文件。

完整接续见 [HANDOFF](../HANDOFF.md)，服务器与新设备准备见 [DEPLOYMENT](DEPLOYMENT.md)，真实验收见 [RELIABILITY](RELIABILITY.md)。
