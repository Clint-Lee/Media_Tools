1. **普通他人视频：你实测的公开 Web 接口拿不到可信播放量，但不能推导为“所有 Web 场景都拿不到”。**  
   恒为 0 不能当真实零播放，空响应、404 也不能证明其他渠道不存在。  
   作者授权后，[官方 `video.data` 接口](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/search-video/video-data)可查询播放数，但须申请权限，不是任意视频查询接口。

2. **第三方不能一概认定为官方 API、Cookie 或估算；须核验具体产品、字段与授权范围。**  
   [蝉妈妈部分素材数据明确标为“预估播放量”](https://www.chanmama.com/yunyingquan/article/2097.html)；不足以据此断言新抖、飞瓜及其全部数据来源，未公开的采集链路和模型不能编造。  
   Cookie 只是登录凭据，不会自动获得查看他人私有数据的权限；普通开发者没有已证实的、免费通查任意视频真实播放量的公开渠道，自有或获授权作品另论。

3. **缺失记 `null`、改展示互动指标是诚实合理的，但 `hot_list.view_count` 不能未经验证就叫“真实播放量”。**  
   接口确实返回数值，不等于已确认其统计对象、时间范围与累计播放口径；建议单独保存并标注“热榜字段值，口径未核验”，核验前不填入真实播放量字段。  
   note 改为“当前接口未提供可核验的该视频播放量”，另行区分请求失败；保留来源、采集时间，点赞/评论/收藏/分享独立展示，不冒充播放量。
