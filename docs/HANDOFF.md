## 当前交接：免登录模式优先

用户明确拒绝注册、扫码、手机验证码等前置门槛。当前`server.js`媒体API使用`lib/guest-access.js`：访客HttpOnly会话、任务/历史/文件所有者隔离、成功操作计额与失败退款、跨站拒绝；账号与管理员仍保留独立权限。`/api/auth/me`在访客处理全过程保持401，没有隐藏演示身份。首个HTML请求先建立同一个访客会话，防止并行API初始化生成不同所有者。

`lib/live-sources.js`的`withPage(...,{anonymous:true})`不注入个人登录Cookie。抖音接官网`/jingxuan`和真实`/aweme/v2/web/module/feed/`；TikTok接`/explore`与真实`/api/explore/item_list/`。真实发布时间严格筛选，缺播放不入榜。公开发现样本的关键词匹配必须标明不是全站搜索。

`lib/tiktok-embed.js`从官方`/embed/v2/作品ID`的当前作品数据提取公开播放地址，核对ID、限制媒体域名、不误取推荐；分享短链先验证实际跳转作品，限制跨站导航。10月15日最终复验实际匿名下载TikTok11,662,978字节、抖音62,616,525字节，均实际解码为H.264+AAC；YouTube读取466句真实字幕。10月15日B站访客原声转写35句、实际语义模型、MP4/MP3及跨访客404再次通过。新回归`test/tiktok-embed.test.js`防止错误作品/媒体域名混入。

公开分区抓取通过请求发起时的epoch隔离旧响应，不以响应抵达时刻决定分区。发现流轮换时，同一完整筛选键下30分钟内实际已发现作品保留并标缓存；原始采集时间、发布时间和指标不改写。`test/source-session.test.js`覆盖旧分区响应晚到、轮换保留与30分钟淘汰。

访客额度：每浏览器会话每日20次、单IP每日60次，解析与新任务分别计次，失败退额；Cookie最长8小时，进程内历史最多100条，完成文件保留1小时。重启后访客额度/历史重置，任务索引单独持久化；不适合直接公开多租户部署。

当前状态以[根交接](../HANDOFF.md)和[免登录平台说明](PLATFORM_CONNECTIONS.md)为准；下面10月12/14日内容仅保留历史审计与部署风险，已过时的平台状态和登录建议不能作现行验收结论。

## 高优先级待办（按顺序接手）

1. **平台真实接入 P0**：在本人合法授权前提下配置平台 Cookie/API Key，逐个平台复测列表、封面、作品ID、原始指标、发布时间、翻页、实际媒体。配置了凭证不等于可用；保留明确错误与最后验证时间。平台不支持或受限制时，不使用静态池、随机播放量、别的平台内容冒充。
2. **排行榜覆盖 P0**：B站榜应继续明确“已发现作品排名”。若产品必须覆盖全站历史，需另建持续采集与可恢复索引、记录覆盖范围；当前多关键词候选无法提供穷举保证。新平台需把官方热搜、热门视频、关键词搜索分开，不以话题名伪造视频。
3. **公开部署安全 P0**：现在是本机单进程服务；平台凭证是服务级共享 `.env` 配置，不是用户隔离的凭证系统。上线前完成 HTTPS、反向代理/可信代理配置、Secure Cookie、租户凭证隔离、容量/速率控制、备份恢复和权限测试。不要直接以当前状态开放公网多人注册。
4. **持久化可靠性 P1**：账号和任务索引是两个 JSON 文件，扣额与任务完成不是跨文件事务；多进程会竞争。**已修复并验证**：队列处理生命周期采用 `try-finally` 确保 `active` 状态必定释放，彻底避免写索引异常导致处理队列死锁；原子写入失败增加临时 `.tmp` 文件的自动清理；任务创建持久化失败支持内存队列与映射安全回滚；`accounts.read()` 与 `publicUser` 增加超过30分钟孤立预占自动回收，防止异常中断泄漏用户配额；扣额回调失败明确记录 `accountWriteFailed` 与错误详情，前端工作台增加醒目告警。多进程/跨文件事务与崩溃演练后续可继续强化。
5. **媒体边界 P1**：已实测 B站52秒原声转写/AI/MP4/MP3及 YouTube真实字幕；其它平台和长视频/HLS直播未完整验收。**已修复并验证**：遗留直链下载接口 `/api/download` 与流媒体代理 `/api/proxy-video` 新增 `resolveMediaExtension`，依据响应头真实 `Content-Type` 动态匹配扩展名（音频匹配为 `.m4a`、`.aac`、`.mp3`，WebM 为 `.webm` 等，不再把所有响应强行标为 `.mp4`）；增加传输断流与截断侦测（`expectedBytes vs bytesReceived` 以及 upstream error 销毁连接），在传输中断时真实记录 `interrupted` 状态，不假报 `sent`；客户端断开连接时自动通知并销毁上游响应，防止僵尸连接泄漏。语音识别/LLM可能误判，继续保留时间戳、引用和非AI降级标识；目前没有画面或镜头理解。
6. **账号产品能力 P2**：注册/密码登录/昵称修改/改密/退出/额度/服务器历史已实现。邮箱验证、邮件找回密码、MFA、付费会员/支付没有实现。管理员只能本机创建，不应恢复演示角色切换。
7. **地球数据口径 P2**：目前是已抓视频内容的城市关联，不是作者IP、拍摄地点或全网来源分布；真正来源需要可靠的原始位置字段或用户确认，不能把关键词推断当真实定位。

可先继续做不依赖外部授权的修复与隔离测试，不必等待所有平台凭证；但缺权限的联网验收必须保留“未完成”，不能写成通过。

## 数据与迁移保护

- 真账号数据库：`.runtime/data/accounts.json`。首次从根 `db.json` 复制迁移，原文件保留；旧3个演示账号禁用，不保留无密码提权。

- 任务索引/结果：`.cache/media/jobs-index.json`及相邻任务目录；已完成结果从完成时间起保留1小时。不要把清理缓存误写成删除整个工作区。

## 交付判据

每个平台必须以真实可访问作品证明：作品身份一致、图片确为该作品、指标取自原源、发布日期明确或注明近似、筛选没有越界、排序/翻页不重复，登录受限时可解释。分析需输出原声或字幕的实际内容和时间戳；下载文件必须真的可解码。账号跨用户不能读任务/文件/历史。

在外部授权与公开部署缺口补齐前，只能交付为“明确能力边界的本机版本”，不能宣布“全平台生产级完成”。本交接文档不是暂停开发，当前开发将继续修复能在现有环境验证的问题，并同步更新实测结果。
