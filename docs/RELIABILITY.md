# 真实数据与媒体处理：运行、验收和边界

## 2026-10-16 可恢复采集索引

实时视频采集成功后，将作品公开元数据保存在 `.cache/collected-videos/<platform>.json`（`HOTPOT_COLLECTION_DIR` 可覆盖），与30分钟实时快照分离。入口“已采集记录”与 `/api/collected-videos` 只查询本机索引，不触发平台抓取；指标为最新一次实际采集值，逐卡标注历史采集时间，不承诺旧作品仍可播放。当前索引不保存搜索词、请求头、Cookie或媒体直链，不从旧素材池补数。

每平台上限50,000件，按最久未采集淘汰。分类为曾采集分区或标题标签匹配，时效严格依原发布日期，未知日期不进入时效榜；最新计数下降或隐藏时不保留更高旧计数。每页30件，游标固定筛选、版本与首批时效参照；数据变化返回409提示刷新。覆盖统计只统计本机保存作品，不是全站覆盖率。

原子替换索引并保存上一版 `.bak`。损坏主文件可恢复上一版（可能损失最新批次），之后写入前保留 `.corrupt-*`；双损坏拒绝覆盖，需人工恢复。写失败不提交内存索引，实时结果仍可展示并附未保存提示。仍仅支持本机单进程，无数据库事务/多写者锁；备份与索引在同一磁盘，不能代替独立灾备。自动积累由实时请求和原有启动预取触发，尚未实现无人值守持续采集器或完整播放量时序库。

新增 `npm run test:collection-ui`（隔离HTTP服务和浏览器，无需已有4000服务），`PUPPETEER_EXECUTABLE_PATH` 可指定本机Chrome；`npm run test:collection-live` 直接调用真实B站并验证入库重载，无需已有服务。故障注入和严格分页测试纳入 `npm test`。本次真实科技3天样本170件全部保存并恢复首批30件，数量不是固定保证。浏览器测试使用隔离作品，仅用于交互验收，不进入正式索引。

更新日期：2026-10-15。当前免登录使用与实测见[平台说明](PLATFORM_CONNECTIONS.md)，待办见[交接](../HANDOFF.md)；10月12日系统审计是历史记录，不能作现行平台状态。本次修复保留既有前端与用户数据，重点纠正数据真实性、匿名访问隔离与媒体处理，不把访问失败包装成成功。

## 2026-10-04 排行榜复核

原来的“全部时间”仅合并6个关键词的前三页和当期榜，且服务端截断到100条。它是局部搜索样本，不能代表全站历史最高播放。本次扩展为22个主要内容领域、官方入站必刷/当期榜/热门候选，首屏30条由官方详情再次核验，不针对两条样例硬编码排名或播放量。继续滚动在本批耗尽后真正请求下一批搜索页，并跨批去重、重新按原始计数排序。仍不是全站历史穷举；界面和API `scope.exhaustive=false` 明确说明这一点。

本机实际核验（数字会增长）：`BV1bW411n7fY`《念诗之王》129,171,748播放；`BV1yt4y1Q7SS`《敢杀我的马》128,920,966播放。两者在鬼畜样本中列前两位；全部分类中排第4、5，因为还有2.45亿/2.03亿的多P课程作品和1.55亿的新宝岛。B站详情的 `stat.view` 是作品累计值，多P数已单独标注，不把它说成第一集播放。

实际分区样本：鬼畜全部时间172条、科技3天内170条、萌宠7天内149条、搞笑3天内179条；科技下一批180条。这些是采集时刻的结果，不是固定凑数目标。未知发布日期不进入时效筛选，未知指标不会补成零播放或虚构数值。

API返回 `scope`（范围/指标/分类方式）、`coverage`（候选/去重后数量/各搜索源成功失败/详情核验数）、`hasMore` 和 `nextCursor`。首批渲染30条，每次新增30条。短时失败最多复用本进程30分钟内的真实采集缓存，返回 `stale=true`、保留原采集时间并明确标“非实时”，不篡改计数或发布时间。页面抓取最多30秒，单个浏览器内接口请求8秒超时，部分失败默认缓存60秒避免频繁请求触发限流；用户刷新可立即重试。

## Windows x64 启动

需要 Node.js、npm、可用的 Python 或 uv，以及能够访问平台/模型仓库的网络。第一次安装会下载 Python 私有环境、FFmpeg 与模型（模型约4GB），不会进入项目的 Git 文件。

```powershell
npm install
npm run setup:media
npm start
```

当前工作区已经安装并验证模型，可直接启动。服务默认只监听 `127.0.0.1:4000`，避免意外公开媒体处理接口。`PORT` 可改端口，`HOST` 可改变监听地址，但公开部署前必须先处理下面的交付边界。

安装脚本只写 `.runtime/`，模型文件校验 SHA256，PyAV 固定为16.1.0以避免 `metadata_errors` 解码兼容错误。安装失败会停止并显示错误；不会声称模型可用。现有大文件如果校验不一致会保留并报错，不自动覆盖。

| `YOUTUBE_API_KEY` | 官方 YouTube Data API 凭证，启用后使用官方分类/精确发布时间/详情播放量和分页。注意平台配额，搜索调用有成本。 |
| `X_BEARER_TOKEN` / `X_SEARCH_ARCHIVE` | X官方凭证与历史检索开关。历史检索需对应权限及额度，开关设1才请求历史接口；没有权限不替代成近7天“历史榜”。 |
| `MEDIA_PROXY` | 显式代理优先于自动检测，先初始化再监听端口。兼容本机Fake-IP时仅已知平台CDN可走配置代理；其它域名仍校验公网DNS。全局代理修改仅管理员可执行。 |

| `LLM_BASE_URL` / `LLM_MODEL` / `LLM_API_KEY` | 可选兼容语义模型服务。默认不需要云端密钥。启用后真实字幕会发送给该服务，应提前告知最终用户。 |

现在会加载项目根目录 `.env`（Node.js 20.12+），现有进程环境优先；可复制 `.env.example` 填写本人授权配置。不要把Cookie/密钥放入源码、日志或公开目录。更改后重启并重新验收，配置存在不等于实际连通。

媒体解析/新任务默认每日20次（上海时区），访客与普通账号均可处理，任务/文件/历史按所有者隔离；访客额外单IP每日60次。处理中预占，成功扣减，失败退回；同所有者复用任务不重复扣减。账号解析统计持久化，访客统计/历史仅当前进程、重启重置；访客HttpOnly Cookie最长8小时，文件完成后保留1小时。遗留 `db.json` 只用于首次导入，新账号数据在 `.runtime/data/accounts.json`；首次迁移备份在 `.runtime/data/.cache/account-backups/`。旧演示角色停用不是删除历史数据。

## 交付边界

- 实测证明被测公开作品链路可运行，不等于所有平台全天候可访问或掌握全站历史榜。B站/抖音/TikTok已有匿名列表与媒体证据，YouTube有公开搜索/字幕证据；红书/快手可靠匿名源仍未完成，X缺运营者API凭证，抖音缺可核实公开播放量。不能宣称“所有平台已高可用交付”。
- 语音识别可能出现同音字、专有名词误差；AI 总结可能理解有误。依据与时间戳可回看核对，不能用于宣称“100%字幕准确”或推断未经识别的画面。
- 作业索引持久化于 `.cache/media/jobs-index.json`，完成后1小时内保留并可跨重启恢复；排队/处理中任务重启后明确标中断，未完成的预占释放，不自动续跑。没有任务文件时不会假报可下载。定时只清理索引中受控 `job-*` 生成目录，不删除用户原视频或不明缓存。缓存不是永久存储。
- 当前为单进程本机服务。公开多人部署仍需HTTPS、反向代理安全配置、容量监控、用户级平台凭证隔离和授权数据接入；不能直接分发包含私人Cookie、账号数据库、测试账号或历史音视频的整个运行目录。
- 只处理自己拥有权利或已获许可的内容；保留平台署名与第三方许可证。默认分析模型为 [Qwen3-4B-Instruct-2507](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507)，原始模型标注 Apache-2.0。分发模型、FFmpeg、运行环境时须保留其原始许可文件，不能只复制整个 `.runtime` 后声称许可审计完成。

## 实现入口

- `lib/live-sources.js`：官方数据请求、缓存/合并、真实媒体字段、城市样本统计。
- `lib/platform-rankings.js` / `lib/youtube-search.js`：各平台真实实体适配、官方API凭证路径、YouTube公开页日期和排序参数。
- `lib/video-pipeline.js`：严格发布时间、计数类型、作品身份及排序。
- `lib/downloader-core.js` / `lib/douyin-sniffer.js`：实际作品解析与身份匹配。
- `lib/media-jobs.js`：作业、字幕轨、原声提取、识别、语义分析及有声下载。
- `lib/accounts.js`：真实账号、会话、每日额度、私有历史；`lib/safe-network.js` / `lib/media-identity.js`：公网地址保护与作品身份核验。
- `lib/transcript-content.js` / `lib/local-analysis.js`：真实SRT、内容依据、字幕语义总结。
- `scripts/setup-media.ps1` / `scripts/transcribe.py`：可复现安装与逐句原声识别。

历史素材JSON仍保留在项目里供既有资料使用，但线上接口不读取它们作为实时榜单，也不动态刷新它们的发布时间。
