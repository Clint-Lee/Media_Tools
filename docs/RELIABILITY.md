## 本轮结果如何理解

10月23日`npm test`的27个入口退出0，新增默认详情生产编排、YouTube成品语义、长任务预占、目录边界和访客跨日/空会话回归。对应修复见[实现记录](IMPLEMENTATION_2026-10-23.md)。**隔离测试成功不等于全平台联网成功。**

此前两个来源测试的Creative Center/详情外访已显式mock。**2026-10-25 起离线套件已有全局禁网守卫**（`test/net-guard.js`，经 `node -r` 挂载到 `npm test` 全部28个入口）：只放行回环与 `*.test` 保留域，外访DNS/直连IP/fetch一律失败；已做反向注入验证（DNS、直连IP、fetch三路均被拦截）。需要真实网络的验收套件不挂守卫。守卫是"离线承诺"的强制门，不代替联网验收。

本次浏览器审查使用临时loopback静态服务、隔离样本、阻断外网：1440/390px首批30条、无整页横向溢出、无JS异常；本地地球/国家标签加载。卡片键盘和弹窗焦点缺陷得到确认。不是实际热榜、网络瓦片或媒体分析验收。

## 测试分层与副作用

| 命令/层级 | 用途 | 前置和副作用 |
|---|---|---|
| `npm test` | 解析、管线、身份、缓存、账号/访客、API等回归 | 使用独立存储和mock；2026-10-25起经 `test/net-guard.js` 强制禁网（回环放行），未声明的出网请求会让测试失败；仍不能作为全平台真实数据证明 |
| `test:metric-ui`、`test:collection-ui`、`test:rankings-ui`、`test:interaction` | 指标/30条批次/筛选/DOM排序/地球交互 | 需可访问本地服务；核心样本/部分瓦片拦截，不是原站真实数据证据，脚本不保证完全禁网 |
| `test:platform-data`、`test:rankings`、`test:discovery`、`test:collection-live` | 实际来源、发布时间、计数、上游翻页与索引 | 会访问平台、刷新源缓存和写采集索引，可能受风控/删除/地区限制；不要对公开服务器反复批量运行 |
| `test:guest-media`、`test:anonymous-media`、`test:guest-ui` | 免登录媒体与访客体验 | 可能下载真实媒体、加载本地模型、消耗实际额度并生成私有文件；先阅读脚本和样例 |
| `test:live`、`test:ui`、`test:accounts-ui`、`test:system` | 完整链路与账号/界面专项 | 部分通过live-auth默认创建/复用真实测试账号；可写实际账号历史/缓存，不应当成无副作用诊断 |
| `scripts/probe-*.js`、`verify-public-metrics.js`等 | 特定来源诊断 | 有外部请求/私有报告；部分脚本写死4000，先核对目标，不自动全部执行 |

浏览器测试依赖可执行Chrome/Chromium；设置PUPPETEER_EXECUTABLE_PATH后还需确认目标脚本真正采用它，当前应用和全部测试的探测方式未完全统一。

## 建议执行顺序

1. 核对Git工作区、目标地址、数据库和缓存目录；不要误把生产服务当测试服务。
2. 先跑 `npm test`，修T01网络隔离及T02/T03断言缺口；需要数据写入的测试使用独立目录和临时账号。
3. 启动专用单实例测试服务；可设HOST=127.0.0.1、HOTPOT_PREWARM=0及私有测试目录，禁止误覆盖正常数据库/索引。
4. 跑隔离浏览器用例，确认30条批次、快速切筛选、真重排、无重复、未知/近似/下界与窄屏。
5. 按平台逐个做真实来源核验，先小样本后扩大；不给失败源补固定素材，不削弱严格门槛。
6. 需要媒体验收时，使用自己有权处理的短公开视频，检查真实字节和音轨，最后才加载ASR/LLM等长时任务。
7. 在目标服务器复测代理/TLS/IP/限流、重启与清理、磁盘不足和备份恢复；不是本机测试可替代的部分。

测试服务的配置、版本、Git提交和样本链接应写进私有报告。不存在的目录/模型要明确报错；不要自动下载大模型来掩盖环境缺失。

## 真实数据验收协议

- **身份**：输入原作品ID与返回作品一致，标题/封面/作者/媒体不拼接推荐作品。
- **指标**：记录原站字段或展示原文、精度、观测时间和来源；动态计数允许注明小时间差，不取历史最大值。播放不能用曝光、互动合计或推算替代。
- **时效**：使用原发布时间；未知不进入严格时效，粗粒度相对时间跨边界时保守排除。服务重启/筛选不改采集时刻。
- **筛选与分页**：分类/关键词意图生效；零命中不退回全部；第2页使用平台支持的真实续页参数（页码/游标），末页如实结束，重复作品不形成新名次。
- **来源范围**：样本内排序/预设账号/第三方转述必须标明，不能声称全网/全站历史穷举。
- **媒体**：实际响应不是HTML/验证页；MP4能解码且有应有音轨，MP3是真实编码而非改扩展名；单次解析成功不代表完整下载。
- **字幕/总结**：真实平台字幕或音频ASR，时间轴有效；重点引用存在于原文并可回看。明确本地/远端LLM/摘录降级，未识别画面不能编造。
- **权限与资源**：不同访客/账号不能互读；长队列/跨日/重启正确结算；断连、超预算、低磁盘和离线过期能安全收尾。

## 证据保存与历史记录

生成的截图、音视频、字幕、测试账号和网络报告保持在忽略于Git的私有目录。不要把Cookie、临时媒体签名URL、真实账号库或授权音视频提交仓库。

旧日期交接中的B站/抖音/TikTok/YouTube下载和转写记录，只证明当时被测作品；本次没有重跑它们。新设备可能没有这些产物，不应将其当作安装依赖。

新结果应说明：提交、目标OS/运行版本、是否匿名、缓存状态、测试类别、实际通过和失败。失败保持失败；严禁为凑“全平台通过”改门槛或把metadata-only升级为播放可用。
