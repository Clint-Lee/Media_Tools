## 这轮修复的真实性/权限问题

1. 取消无需密码就能切换admin/pro的接口与界面。旧演示账号隔离，真实管理员仅通过本机 `npm run account:create-admin` 创建。没有会员付费、自助提权或“无限并发”的假能力。
2. 密码使用随机盐scrypt；会话由加密安全随机数生成，服务端只保存哈希，浏览器使用HttpOnly/SameSite Cookie。注册后真实登录，退出在服务端撤销；密码修改使旧会话失效。账号可改昵称，未知旧注册时间不再填固定日期。
3. 普通账号上海时区每天20次媒体处理。解析与新任务分别预占一次；失败释放、成功扣减，复用任务不重复扣减。额度从服务端读取，移除固定“5/20”“20次剩余”。
4. 任务、结果文件、处理历史按账号归属验证。跨账号查询任务或文件返回404。历史区分“解析”“已生成”“服务器已发送”“预览片段”和“失败”，不把点击/解析当成已下载。
5. 原图校验真实JPEG/PNG/WebP/GIF/AVIF字节；严格下载失败返回502，不返回占位SVG。ZIP部分失败有FAILED.txt与缺失数量，全部失败不生成空ZIP。图文BGM也须实际转MP3。
6. 嗅探失败不再宣称取得了“原站播放凭证”。抖音ID双重转义错误修复；红书和快手不再抽取页面中的第一个推荐作品。所有通用解析验证返回媒体与输入作品身份一致。
7. YouTube/TikTok增加官方嵌入播放器（是否播放仍取决于网络及作者允许嵌入）；不把缺失的平台URL构造成B站URL。
8. 任务索引持久化，完成结果重启恢复；中断任务明确失败，不能显示“完成”。模型不可用的摘录明确标注非AI语义总结。
9. 根目录.env可加载，配置不输出到日志。代理检测不再用YouTube首页200作为唯一条件，先初始化再监听；已知平台CDN受控兼容Fake-IP，未知域名仍拒绝内网解析与不安全重定向。

设计依据：使用 [Node.js crypto](https://nodejs.org/docs/latest-v20.x/api/crypto.html) 的scrypt/随机数能力并参考 [OWASP会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)。通用媒体依赖依照 [yt-dlp官方依赖说明](https://github.com/yt-dlp/yt-dlp#dependencies) 安装default组件；没有启用远端组件或全局插件。
